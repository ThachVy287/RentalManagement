# Rental Management System

## Giới thiệu

Hệ thống quản lý phòng trọ giúp chủ trọ quản lý các hoạt động:
- Quản lý phòng
- Quản lý người thuê
- Quản lý hợp đồng
- Quản lý dịch vụ
- Quản lý hóa đơn
- Báo cáo doanh thu


## Công nghệ sử dụng

### Frontend
- Next.js
- ReactJS
- Tailwind CSS


### Database
- SQL Server


### Backend
- ASP.NET Core Web API


## Chức năng hệ thống

### Admin

- Dashboard thống kê tổng quan
- Quản lý phòng
- Quản lý người thuê
- Quản lý hợp đồng
- Quản lý dịch vụ
- Quản lý hóa đơn
- Xem báo cáo doanh thu
